# 现金流量图与资金等值公式
现金流量示例中，第 1、2 年末分别流出 100、150，第 3 年末流入 200，图中第 n−1 和第 n 年末也各流入 200。
P 为现值，F 为终值，A 为每期期末等额收付额，i 为期利率，n 为期数。
= F=P(1+i)^n
= P=F(1+i)^{-n}
= F=A\frac{(1+i)^n-1}{i}
= A=F\frac{i}{(1+i)^n-1}
= P=A\frac{(1+i)^n-1}{i(1+i)^n}
= A=P\frac{i(1+i)^n}{(1+i)^n-1}

# 名义利率与实际利率
例题：名义年利率为 12%，按季度、按月和按日计息时，实际年利率分别是多少？
设 r 为名义年利率，m 为一年内的计息次数。
= i_{\rm eff}=\left(1+\frac{r}{m}\right)^m-1
每季度计息一次
= i_{\rm eff}=(1+12\%/4)^4-1\approx12.55\%
每月计息一次
= i_{\rm eff}=(1+12\%/12)^{12}-1\approx12.68\%
每天计息一次，按一年 365 天计算
= i_{\rm eff}=(1+12\%/365)^{365}-1\approx12.75\%

# 现金流量图的含义
现金流量是一个经济系统在某个时点实际发生的资金流入或流出。现金流量图用时间轴表示一段时间内发生的现金流量。
线段长度表示金额，箭头向上表示流入、向下表示流出，横轴数字表示时间点。时间点“1”表示第一年末，也表示第二年初。
示例中的第 1 年末流出 100，第 2 年末流出 150，第 3 年末流入 200，第 n−1 年末和第 n 年末各流入 200。读图需同时识别大小、方向和时间点。

# 建设期利息

# 经营成本
经营成本是财务分析中对现金流量分析时使用的特定概念，构成项目运营期现金流出的主体。

# 总成本费用的两种估算方式
总成本费用是运营期内一定时期（项目评价通常为一年）为生产和销售产品、提供劳务所发生的全部费用。
生产成本加期间费用估算法需要先将生产费用分配给产品。
= \text{总成本费用}=\text{生产成本}+\text{期间费用}
= \text{期间费用}=\text{管理费用}+\text{营业费用}+\text{财务费用}
生产要素估算法
= \text{总成本费用}=\text{外购原材料、燃料和动力费}+\text{工资及福利费}+\text{折旧费}+\text{摊销费}+\text{修理费}+\text{财务费用}+\text{其他费用}
等价的成本分解为
= \text{总成本费用}=\text{经营成本}+\text{折旧费}+\text{摊销费}+\text{财务费用}

# 资本金与债务资金的筹措
项目资本金的筹措方式包括股东直接投资、股票融资及政府投资。
债务资金的筹措方式包括信贷融资（贷款）、债券融资（企业债券）、融资租赁、既有法人内部融资等。优先股和可转换债券列为准股本资金。
优先股介于股本资金和负债之间。优先股股东通常不参与经营管理，领取固定股息，一般不再参加红利分配。其受偿顺序先于普通股股东，后于其他债权人。
可转换债券具有可转换性、债权性和股权性。在规定期限内，投资者可以按转换价格将债券转换为一定数量的股票，也可以选择不转换。

# 普通股资金成本
普通股资金成本可用股利折现模型、资本资产定价模型或税前债务成本加风险溢价法估算。
固定股利政策：每年分配现金股利 D。
= K_s=\frac{D}{P_0(1-f)}
固定增长股利政策：第一年股息为 D₁，之后按固定增长率 G 增长。
= K_s=\frac{D_1}{P_0(1-f)}+G
P₀ 为普通股筹资额，f 为筹资费用率，Kₛ 为普通股股东要求的收益率。
例题：发行普通股筹资 5000 万元，筹资费率 4%，第一年股利率 12%，以后每年增长 5%。普通股资金成本为
= K_s=\frac{5000\times12\%}{5000(1-4\%)}+5\%=17.5\%

# 资本资产定价模型
= K_s=R_f+\beta(R_m-R_f)
R𝒇 为无风险报酬率，Rₘ 为市场投资组合报酬率，β 为股票的贝塔系数。
例题：无风险利率为 6%，市场回报率为 8%，股票的 β 为 1.5。资金成本为
= K_s=6\%+1.5(8\%-6\%)=9\%
税前债务成本加风险溢价法考虑股票投资比债券投资承担的额外风险。
= \text{普通股资本成本}=\text{债务资本成本}+\text{股票投资的额外风险报酬率}

# 优先股资金成本
Kₚ 为优先股成本率，Dₚ 为每年股息，P₀ 为票面值，i 为股息率，f 为筹资费率。按面值发行时
= K_p=\frac{D_p}{P_0(1-f)}=\frac{P_0 i}{P_0(1-f)}=\frac{i}{1-f}
例题：发行优先股，面值共 200 万元，筹资费率为 4%，年股息率为 14%。资金成本率为
= K_p=\frac{14\%}{1-4\%}\approx14.58\%

# 五种盈利能力指标
财务净现值（FNPV）、财务内部收益率（FIRR）、静态投资回收期（Pₜ）、总投资收益率（ROI）和项目资本金净利润率（ROE）。
财务净现值是各期净现金流量在基准时点折现值的代数和。
= \mathrm{FNPV}=\sum_{t=1}^{n}\frac{(CI-CO)_t}{(1+i_c)^t}
CI 为现金流入，CO 为现金流出，t 表示年份，n 为计算期，i𝑐 为折现率。财务净现值大于或等于零时，方案在该折现率下可接受；小于零时不可接受。

# 总投资收益率与项目资本金净利润率
总投资收益率表示项目总投资的获利能力。
= \mathrm{ROI}=\frac{\mathrm{EBIT}}{TI}\times100\%
= \mathrm{EBIT}=\text{利润总额}+\text{计入总成本费用的利息费用}
EBIT 为正常年份的年息税前利润或经营期内年平均息税前利润，TI 为项目总投资。
项目资本金净利润率表示项目资本金的获利能力。
= \mathrm{ROE}=\frac{NP}{EC}\times100\%
NP 为正常年份的年净利润或经营期内年平均净利润，EC 为项目资本金。

# 财务内部收益率的插值计算
例题：根据各年年末的净现金流量估算该项目的内部收益率。
| 年末 | 0 | 1 | 2 | 3 | 4 | 5 |
| 净现金流量 | −1000 | −800 | 500 | 500 | 500 | 1200 |
| 试算折现率 | 财务净现值 |
| 10% | 148.22 |
| 12% | 38.87 |
| 13% | −11.89 |
取净现值一正一负的两个试算点进行线性插值。
= \mathrm{IRR}\approx i_1+(i_2-i_1)\frac{\mathrm{NPV}_1}{\mathrm{NPV}_1-\mathrm{NPV}_2}
= \mathrm{IRR}\approx12\%+(13\%-12\%)\frac{38.87}{38.87+11.89}\approx12.77\%

# 静态投资回收期

= P_t=3+\frac{30}{30+20}=3.6\ \text{年}

# 偿债能力指标
利息备付率（ICR）表示息税前利润可覆盖当期应付利息的倍数。
= \mathrm{ICR}=\frac{\mathrm{EBIT}}{PI}
PI 为计入总成本费用的应付利息。指标越高，付息保障程度越高。正常运营的企业通常应大于 1。
偿债备付率（DSCR）表示可用于还本付息的资金对当期应还本付息金额的覆盖倍数。
= \mathrm{DSCR}=\frac{\mathrm{EBITDA}-T_{\rm AX}}{PD}
EBITDA 为息税折旧摊销前利润，T 为企业所得税，PD 为当期应还本金和利息。该比率大于 1，表明当期资金可覆盖当期债务本息。上述两指标若以百分数表示，应将倍数乘以 100%。
另一项偿债能力指标为资产负债率。

# 资产负债率
= \mathrm{LOAR}=\frac{TL}{TA}\times100\%
TL 为期末负债总额，TA 为期末资产总额。该指标反映项目的总体偿债能力。在其他条件相同时，资产负债率越低，总体偿债能力越强。

# 影子价格
影子价格是经济费用效益分析中对投入物或产出物使用的计算价格，反映资源的供求状况和稀缺程度。
= \text{出口产出物影子价格（出厂价）}=\mathrm{FOB}\times\text{影子汇率}-\text{出口费用}
= \text{进口投入物影子价格（到厂价）}=\mathrm{CIF}\times\text{影子汇率}+\text{进口费用}
FOB 表示离岸价，CIF 表示到岸价。
= \text{影子汇率}=\text{外币牌价}\times\text{影子汇率折算系数}

# 盈亏平衡分析
例题：设计年产量 3 万吨，总生产成本 1352.18 万元，固定成本 112.94 万元，单位可变成本、税金与单位产品增值税合计 413.08 元/吨，单位售价 579.82 元/吨。收入和成本均为含税价格。
设固定成本为 C𝒇，单位变动费用为 Cₙ，单位售价为 P，盈亏平衡产量为 N*。销售收入线与总成本线的交点为盈亏平衡点。原稿在列式时混用了万元和元，下式先把固定成本换算成元，再以吨为单位计算产量。
= C_F+C_N N^*=PN^*
= N^*=\frac{C_F}{P-C_N}=\frac{112.94\times10^4}{579.82-413.08}\approx6773.42\ \text{吨}
= \mathrm{BEP}_{\rm utilization}=\frac{6773.42}{30000}\times100\%\approx22.6\%
开工率达到设计产能约 22.6% 时可以保本。

# 敏感性系数和临界点
评价指标 A 对不确定因素 F 的敏感性系数等于二者相对变化率的比值。
= S_{AF}=\frac{\Delta A/A}{\Delta F/F}
系数为正表示同方向变化，为负表示反方向变化。绝对值越大，指标对该因素的变化越敏感。
以基准收益率作为计算临界点的依据时，同一项目的基准收益率越高，临界点通常越低。在给定基准收益率下，达到临界点所需的不利变化幅度越小，项目越敏感。

# 效益比选
方法包括净现值法、净年值法、差额内部收益率法和差额净现值法。
净现值比较法
= \mathrm{NPV}(i_c)=\sum_{t=1}^{n}(CI-CO)_t(1+i_c)^{-t}
净年值比较法
= \mathrm{NAV}(i_c)=\mathrm{NPV}(i_c)(A/P,i_c,n)
净现值、净年值均为正的方案可选。在可比条件下，其值越大越优。比较寿命期不等且可重复实施的互斥方案时，采用净年值较方便。

# 差额内部收益率与差额净现值
用投资大的方案减去投资小的方案，构造增量净现金流量。
= \Delta CF_t=(CI-CO)_{\text{大},t}-(CI-CO)_{\text{小},t}
= \sum_{t=1}^{n}\Delta CF_t(1+\Delta\mathrm{FIRR})^{-t}=0
= \Delta\mathrm{NPV}=\sum_{t=1}^{n}\Delta CF_t(1+i_c)^{-t}
在常规增量现金流条件下，若差额内部收益率高于基准收益率，或差额净现值为正，增投部分可接受，宜选投资较大的方案。

# 费用现值法
= PC=\sum_{t=0}^{n}(C_t+V_t)(1+i_c)^{-t}-S(1+i_c)^{-n}
PC 是方案的费用现值，Cₜ 是第 t 年的投资，Vₜ 是第 t 年的运行费用，S 是期末残值，i𝑐 是基准收益率，n 是计算期。效益相同时，费用现值较小者较优。
@32
# 费用现值法的应用
例题：工艺管道有 A、B 两个设计方案。二者寿命均为 8 年，基准收益率 10%。金额单位为万元。
| 方案 | 投资额 | 年运行费用 | 期末残值 |
| A | 1000 | 400 | 200 |
| B | 1500 | 300 | 100 |
= PC_A=1000+400(P/A,10\%,8)-200(P/F,10\%,8)
= PC_A=1000+400\times5.3349-200\times0.4665=3040.66\ \text{万元}
= PC_B=1500+300(P/A,10\%,8)-100(P/F,10\%,8)
= PC_B=1500+300\times5.3349-100\times0.4665=3053.82\ \text{万元}
方案 A 的费用现值较小，选 A。

# 费用年值法
= AC=\left[\sum_{t=0}^{n}(C_t+V_t)(1+i)^{-t}-S(1+i)^{-n}\right](A/P,i,n)
例题：基准收益率为 15%，比较两个设备工程方案。金额单位为万元。
| 方案 | 投资额 | 寿命 | 年运行费用 | 残值 |
| 甲 | 1800 | 6 年 | 550 | 200 |
| 乙 | 2600 | 10 年 | 400 | 300 |
= AC_{\text{甲}}=[1800+550(P/A,15\%,6)-200(P/F,15\%,6)](A/P,15\%,6)
= AC_{\text{甲}}\approx(1800+550\times3.784-200\times0.432)/3.784\approx1002.85\ \text{万元/年}
= AC_{\text{乙}}=[2600+400(P/A,15\%,10)-300(P/F,15\%,10)](A/P,15\%,10)
= AC_{\text{乙}}\approx(2600+400\times5.019-300\times0.247)/5.019\approx903.27\ \text{万元/年}
乙方案费用年值较低，选乙。

# 计算期不同的互斥方案
最小公倍数法：在方案可重复实施的假设下，把各方案重复到寿命期的最小公倍数，再比较净现值。计算较繁，且技术进步可能使原样重复的假设脱离实际。
年值法：用净年值比较各方案。
研究期法：当备选方案的计算期不能向后延续时，人为选取同一个研究期，计算研究期内现金流量的净现值并比较。

# 价值工程
核心是对产品或作业进行功能分析，目的是以尽可能低的寿命周期成本实现必要功能，提高产品或作业的价值。
= V=\frac{F}{C}=\frac{\text{功能评价值（目标成本）}}{\text{现实成本}}
提高价值的五种途径：功能提高且成本降低；成本不变而功能提高；功能不变而成本下降；功能略降而成本下降幅度更大；成本略增而功能提高幅度更大。

# 价值工程对象的选择
经验分析法（因素分析法）：综合考虑影响因素，简便易行，无需特殊训练，适合资料不足或时间紧迫的情况。缺点是缺少定量依据，结果依赖工作人员的知识、经验与态度。
百分比法：依某项费用或资源在不同产品中所占的比重选择分析对象。
ABC 分析法：A 类零部件品种少、成本比重大，是重点分析对象。B 类为次要零部件，有时可将 A、B 合并作为分析对象。C 类零部件数量多，对总体成本影响较小。
强制确定法（价值系数法）：先确定部件的功能重要性系数和现实成本系数，再计算价值系数以确定研究对象。功能打分可用 01 法或 04 法。01 法逐一比较部件，较重要者记 1 分，另一方记 0 分，某部件得分与总得分之比即其功能重要性系数。

# 功能分析与功能评价
例题：产品由 A、B、C、D 四个零部件组成，价值指数依次为 1.8032、1.4246、1.0000 和 0.6419。通常哪个部件不作为价值工程分析对象？
价值系数等于或接近 1，表示功能的重要性与成本比重相当，通常不优先作为分析对象。答案为 C。

# 功能成本改进期望值
例题：整体功能目标成本为 5000 元，功能 F 的功能评价系数为 0.2，现实成本为 1500 元。
= \text{功能 F 的目标成本}=5000\times0.2=1000\ \text{元}
= \text{目标成本}-\text{现实成本}=1000-1500=-500\ \text{元}
按讲义的差额定义，负号表示应将该功能成本降低 500 元。
部件价值指数例题：A、B、C、D 的价值指数分别为 1.8032、1.4246、1.0000、0.6419。指数为 1 的 C 部件功能重要性与成本比重相当，通常不优先作为价值工程分析对象。
