# 道尔顿分压定律
理想气体混合物的总压等于各组分分压之和。
= p_{\text{总}}=p_A+p_B+\cdots=\sum_i p_i
各组分的分压等于总压乘以该组分的摩尔分数。
= x_i=\frac{n_i}{n}
= p_i=\frac{n_i}{n}p_{\text{总}}=x_i p_{\text{总}}

# 氧化还原反应与电极电势
25 ℃ 时，用常用对数写出的能斯特方程如下。其中 n 为转移电子数，a、b 为反应式相应的计量数，标准态电势以 φ° 表示。
= \varphi=\varphi^\circ+\frac{0.05917\,\mathrm{V}}{n}\lg\frac{[c(\text{氧化态})/c^\circ]^a}{[c(\text{还原态})/c^\circ]^b}
将两个依次进行的还原半反应相加，可以利用电子数求合成电对的标准电极电势。
= \varphi_3^\circ=\frac{n_1\varphi_1^\circ+n_2\varphi_2^\circ}{n_1+n_2}

# 弱酸和弱碱的解离
HAc 为乙酸的简写。以下为浓度式，c₀ 为初浓度，近似式适用于解离度较小的情况。
= K_a=\frac{c(\mathrm{H^+})c(\mathrm{Ac^-})}{c(\mathrm{HAc})}
= c(\mathrm{H^+})\approx\sqrt{K_a c_0}
= K_b=\frac{c(\mathrm{NH_4^+})c(\mathrm{OH^-})}{c(\mathrm{NH_3})}
= c(\mathrm{OH^-})\approx\sqrt{K_b c_0}
弱酸和弱碱的解离度分别近似为
= \alpha=\frac{c(\mathrm{H^+})}{c_0}\approx\frac{\sqrt{K_a c_0}}{c_0}=\sqrt{\frac{K_a}{c_0}}
= \alpha=\frac{c(\mathrm{OH^-})}{c_0}\approx\frac{\sqrt{K_b c_0}}{c_0}=\sqrt{\frac{K_b}{c_0}}

# 吉布斯自由能与反应方向
= \Delta_\mathrm{r}G_\mathrm{m}^\circ=\Delta_\mathrm{r}H_\mathrm{m}^\circ-T\Delta_\mathrm{r}S_\mathrm{m}^\circ
等温等压且只做体积功时，实际反应吉布斯自由能变小于零，反应可正向自发进行。在标准态近似的温度范围内，可依据焓变和熵变比较。
| 焓变 | 熵变 | 正向自发反应的温度条件 |
| 负 | 正 | 各温度下均有利 |
| 正 | 负 | 各温度下均不利 |
| 正 | 正 | 高温有利 |
| 负 | 负 | 低温有利 |
以焓变和熵变近似恒定求得转折温度
= T_c=\frac{\Delta H}{\Delta S}
与标准平衡常数的关系
= \ln K^\circ=-\frac{\Delta_\mathrm{r}G_\mathrm{m}^\circ}{RT}=-\frac{\Delta_\mathrm{r}H_\mathrm{m}^\circ}{RT}+\frac{\Delta_\mathrm{r}S_\mathrm{m}^\circ}{R}

# 标准平衡常数
对于以下反应
= a\mathrm A+b\mathrm B\rightleftharpoons g\mathrm G+d\mathrm D
液相以理想稀溶液浓度比近似活度。
= K^\circ=\frac{[c(\mathrm G)/c^\circ]^g[c(\mathrm D)/c^\circ]^d}{[c(\mathrm A)/c^\circ]^a[c(\mathrm B)/c^\circ]^b},\qquad c^\circ=1\,\mathrm{mol/L}
理想气相用分压比表示。
= K^\circ=\frac{[p(\mathrm G)/p^\circ]^g[p(\mathrm D)/p^\circ]^d}{[p(\mathrm A)/p^\circ]^a[p(\mathrm B)/p^\circ]^b},\qquad p^\circ=100\,\mathrm{kPa}
计量数同乘 n 时，平衡常数变为原值的 n 次方；反应逆转时，平衡常数变为倒数。
= K_{\text{新}}^\circ=(K^\circ)^n,\qquad K_{\text{逆}}^\circ=1/K^\circ
两个反应相加或相减时，相应的平衡常数分别相乘或相除。
= K_{1+2}^\circ=K_1^\circ K_2^\circ
= K_{1-2}^\circ=K_1^\circ/K_2^\circ
