# 一、静力学
# 1. 静力学的基本概念及基本原理
# 1.1 力的基本概念
力是物体间的机械相互作用。力可以使物体的机械运动状态发生改变，速度大小或方向的改变都属于运动状态的改变。
力是矢量，其三要素为大小、方向和作用点。
力的外效应是改变物体的运动状态，属于静力学研究的对象；内效应是使物体变形，属于材料力学研究的对象。
力可直接作用，例如推车、两物体碰撞；也可通过场作用，例如重力场、电场、磁场。
# 1.2 力的表示与常见的力
用带箭头的线段表示力，长度按比例表示大小，箭头表示方向，起点可表示作用点。用带箭头的 F 表示力矢量，用 F 表示力的大小。
集中力的单位为牛顿（N）或千牛（kN）。分布力沿一定长度分布，其线集度 q 的单位为 N/m 或 kN/m。
# 1.3 质点、平衡与刚体
质点是具有质量的理想点。在研究的问题中，物体的大小和形状对所考察的运动影响很小时，可以把物体看作质点。
在惯性参考系内，物体受到若干力作用仍保持静止或匀速直线运动，称为平衡。刚体是受力时内部任意两点间距离保持不变的理想模型。研究平衡时，若变形相对于几何尺寸很小，可视为刚体。
# 1.4 力的平行四边形法则
作用于同一点的两个力可以合成为作用于该点的一个力。以两力为邻边作平行四边形，从公共起点引出的对角线表示合力的大小和方向。也可用力的三角形求合力。

# 1.5 力的平衡及其推论
刚体受两力而平衡的充分必要条件是两力大小相等、方向相反，且沿同一直线。
@0
绳索只能受拉。二力细杆可以受拉，也可以受压，力的作用线沿杆轴。
力的可传性：作用于刚体的力沿其作用线移动到刚体内任一点，作用效果不变。
三力平衡汇交定理：刚体在三个力作用下平衡，若其中两力作用线相交，则三力共面，第三力的作用线通过交点。
# 1.6 斜面上刚体的受力分析
斜面上的物体可受到重力、斜面的法向支持力和摩擦力。重力竖直向下，沿斜面方向的分量向下，法向分量指向斜面。支持力垂直于斜面并指向物体。
摩擦力沿斜面，与接触面间的相对运动或其趋势相反。静摩擦力的大小随平衡所需的切向力变化，其上限由静摩擦系数 μₛ 和法向支持力 N 确定。φ 为摩擦角。
= f_{s,\max}=\mu_sN=N\tan\varphi
超过该上限会发生相对滑动。滑动摩擦力的大小由动摩擦系数 μₖ 决定。
= f_k=\mu_kN
物体平衡时合力为零，可沿斜面和法线方向列平衡方程，也可选水平与竖直方向。

::003
设斜面倾角为 α，重力大小为 G。在仅受重力、支持力和摩擦力作用的平衡状态下，支持力抵消重力的法向分量，静摩擦力抵消其切向分量。
= N=G\cos\alpha
= f_s=G\sin\alpha
若在水平方向和竖直方向列平衡方程，同样可得静止所需条件。
= N\cos\alpha+f_s\sin\alpha=G
= N\sin\alpha=f_s\cos\alpha
= \tan\alpha\leq\mu_s=\tan\varphi
# 1.7 约束力
自由体可以在空间作任意位移；位移受到限制的物体称为非自由体。周围物体施加的位移限制称为约束，对被约束物体的作用力称为约束力。
约束力作用在接触处，其方向与约束所阻碍的位移相反，大小需通过受力分析确定。
柔软体约束可由绳索、胶带或链条形成。柔索只能承受拉力，约束力沿柔索离开被约束物体。皮带对轮的拉力沿轮缘切线。

# 固定铰链、辊轴和固定端约束
固定铰链把构件和支座的圆孔用圆柱销连接，允许构件绕销轴转动。约束反力通过销轴中心。外载变化时，反力大小和方向均可改变，可用两个相互垂直的分力表示。
辊轴支座可看成在铰链支座下放置辊轴。理想支座沿光滑支承面的法线提供约束反力。
平面内的固定端既限制平移，也限制转动。其约束作用可用两个正交分力和一个约束力偶表示，方向可先假设再由平衡求得。
# 2. 力系的简化
# 2.1 力系
作用在物体上的一组力称为力系。各力作用线位于同一平面的称为平面力系，不能置于同一平面的称为空间力系。
# 2.2 力对点和轴的矩
力矩度量力使物体转动的效果。矢径 r 从矩心 O 指向力 F 的作用点，力对 O 的矩为两矢量的叉积。
= \boldsymbol M_O=\boldsymbol r\times\boldsymbol F
设 θ 为 r 与 F 的夹角，h 为矩心到作用线的垂直距离（力臂）。力矩的大小为
= |\boldsymbol M_O|=rF\sin\theta=Fh
平面问题通常取逆时针为正，顺时针为负。力矩量纲为 ML²T⁻²。力对轴的矩为力矩矢量在该轴上的投影。

::005
# 力偶与力偶矩
两个等值、反向且不共线的平行力构成一个力偶。两作用线之间的垂直距离为力偶臂，两作用线所决定的平面为力偶作用面。
力偶矩度量力偶的转动效应。平面问题中通常取逆时针为正，顺时针为负。力矩和力偶矩的单位均为 N·m 或 kN·m。
力对点的矩与矩心的位置有关；力偶矩与矩心选择无关，力偶对刚体的作用可以完全由力偶矩描述。计算平面内的合矩时，可将各力矩和各力偶矩按同一符号约定相加。
# 2.3 力系的简化
汇交力系中，各力可沿自身作用线移动至汇交点，再用向量加法合成作用于该点的合力。
选定简化中心 O 后，力系对 O 的主矩等于各力对 O 的矩与各力偶矩之和。

# 3.2 力系平衡条件
刚体静止时既不能平移也不能转动，所有外力的矢量和为零，对任意点的外力矩之和也为零。
= \sum_i\boldsymbol F_i=\boldsymbol0
= \sum_i\boldsymbol M_O(\boldsymbol F_i)+\sum_i\boldsymbol m_i=\boldsymbol0
先按约束特点画出反力，再选取便于消去未知量的矩心。可把若干刚体作为整体，也可单独隔离某个构件。
# 3.3 静定桁架
桁架由杆件组成，常用于大跨度结构。理想铰接桁架的荷载作用于节点时，直杆是二力杆，只传递轴力，杆的横截面上正应力均匀分布。
可以由各节点的力平衡判断杆件轴力和零杆。把连接杆的作用力沿杆轴画在节点上，逐个分析节点，检查哪些杆必须具有零轴力才能满足平衡条件。

# 2. 刚体的基本运动
刚体的基本运动包括平动和定轴转动。刚体平动时，其上任意线段的方向保持不变，同一瞬时各点的速度相同、加速度相同，各点轨迹可以相互平移重合。

# 三、动力学
# 1. 动力学基本定律及质点运动微分方程
牛顿第一定律：物体保持静止或匀速直线运动状态，直到外力迫使它改变这种状态。
牛顿第二定律：质点的加速度与合外力成正比，与质量成反比，方向与合外力相同。
牛顿第三定律：两物体间的作用力与反作用力大小相等、方向相反，沿同一直线，分别作用于两个物体。
# 1.2 质点运动微分方程

# 4.2 动量与动量守恒
质点的动量为质量与速度矢量的乘积，方向与速度相同，单位为 kg·m/s。
= \boldsymbol p=m\boldsymbol v
系统的总动量等于总质量与质心速度的乘积。
= \boldsymbol p_{\rm total}=m\boldsymbol v_C
系统所受合外力为零时，总动量守恒。若沿某一方向的合外力分量为零，则总动量在该方向的分量守恒。
