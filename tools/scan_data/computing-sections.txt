## 1.2 机器数
机器数是数值信息在计算机中的编码，符号也用二进制位表示。计算机可用原码、反码和补码表示有符号整数。
原码的最高位是符号位，0 表示正、1 表示负，其余位表示绝对值。正数的反码和补码都与原码相同。负数的反码由原码的数值位逐位取反得到，负数的补码由反码加 1 得到。
以 8 位整数为例。

8421 BCD 码用 4 个二进制位表示一个十进制数字，四位从高到低的权分别为 8、4、2、1。

十进制数 32 的 BCD 码是 0011 0010；89 的 BCD 码是 1000 1001；56 的 BCD 码是 0101 0110。

# ASCII 码
ASCII 是美国信息交换标准代码（American Standard Code for Information Interchange）的简称。标准 ASCII 用 7 位表示 128 种字符，常以一个字节存放一个字符；8 位扩展编码可容纳 256 个不同的码值。
# 汉字国标码
GB 2312—80 收录了 6763 个常用汉字，每个汉字对应两个字节。汉字国标码的两个字节最高位均为 0。为与 ASCII 区分，相关机内码把各字节最高位置 1，相当于各字节加 128。
# 图形信息
矢量图形通过几何对象及其属性表示图形。位图把图像分成 M 行、N 列的像素，按矩阵记录各像素值。灰度图记录亮度，彩色图可分别保存红（R）、绿（G）、蓝（B）三个分量。
分辨率 640 × 480 表示每行 640 个像素、共 480 行。影响图像质量和存储量的因素包括分辨率、颜色深度、图像尺寸和文件格式。
# 十进制
使用 0 至 9，逢十进一。例如
= (571.34)_{10}=5\times10^2+7\times10^1+1\times10^0+3\times10^{-1}+4\times10^{-2}
= 500+70+1+0.3+0.04=571.34
# 二进制
使用 0 和 1，逢二进一。计算机内部信息采用二进制表示。例如
= (110.01)_2=1\times2^2+1\times2^1+0\times2^0+0\times2^{-1}+1\times2^{-2}=6.25

# 十六进制与数值转换
使用 0 至 9 和 A 至 F，A 至 F 分别表示十进制 10 至 15。逢十六进一。
= (3AF.C)_{16}=3\times16^2+10\times16^1+15\times16^0+12\times16^{-1}=943.75
比较不同进制的数时，可以先按位权展开，分别换成十进制数，再比较数值。
# 计算机病毒
计算机病毒是具有自我复制能力、能影响计算机功能或损坏数据的程序或指令。其特点包括传播性、隐蔽性、感染性、潜伏性、可激发性及破坏性。资料列出的生命周期依次为开发期、传染期、潜伏期、发作期、发现期、消化期、消亡期。
# 信息保密
信息隐藏将秘密信息嵌入普通媒体，降低通信行为被察觉的可能。信息加密用密码算法保护传输或存储过程中的数据，将明文变成密文。资料提到传统密码、对称密码、公钥密码和数字签名。
数字签名可用于验证数据完整性、确认发送方身份，并为防止交易抵赖提供依据。
