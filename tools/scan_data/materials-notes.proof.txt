# 1.2 材料拉伸时的力学性能
常温静载试验将材料制成标准试件，在万能材料试验机上逐步加载，观察材料的变形和破坏，记录拉力 F 与伸长量 Δl 的关系。
力—伸长量曲线受试件长度和截面积影响。用原始截面积 A、初始标距 l 定义工程应力和工程应变，可将实验结果表示为应力—应变曲线。
= \sigma=\frac{F}{A}
= \varepsilon=\frac{\Delta l}{l}
弹性阶段：曲线初段 Oa 为直线，应力与应变成正比，斜率对应弹性模量 E。点 a 对应比例极限 σₚ。在线弹性范围内服从拉压胡克定律。
= E=\frac{\sigma}{\varepsilon},\qquad \sigma=E\varepsilon
屈服阶段：超过 b 点后，应力基本不变而应变明显增加。舍弃第一个谷值后，屈服阶段的最低应力定义为下屈服强度 σₛ。
磨光试件在屈服时可出现与轴线约成 45° 的条纹，这是材料内部相对滑移形成的滑移线。

# 强化、颈缩与拉断
经过屈服后，要使材料继续变形必须增大应力，这个阶段称为强化阶段。最高点 e 对应抗拉强度 σᵦ，是工程应力的最大值，也是衡量材料强度的重要指标。
越过 e 点后，试件局部横向尺寸迅速缩小，形成颈缩。继续伸长所需的拉力降低，按原始面积计算的工程应力随之下降，到 f 点试件拉断。
# 伸长率与断面收缩率
拉断后仍留下塑性变形。把断后标距 l₁ 与原始标距 l 的差相对于原标距的百分数定义为伸长率。

# 卸载定律与冷作硬化
在强化阶段 d 点卸载，应力与应变沿近似平行于初始弹性直线 Oa 的斜线 dd′ 变化，卸载后留有残余应变。短期内重新加载时，大致沿原卸载线回升至 d 点，然后转入后续强化曲线。再次加载的弹性范围提高，但塑性和剩余伸长能力降低，这种现象称为冷作硬化。
# 1.3 材料压缩时的力学性能
金属压缩试件一般制成短圆柱，以免被压弯；混凝土和石料可制成立方体试块。
低碳钢压缩时的弹性模量和屈服强度与拉伸时大致相同。铸铁的抗压强度明显高于抗拉强度，抗剪强度介于两者之间。混凝土、石料等脆性材料同样抗压强而抗拉弱，可用于受压构件。细长受压构件还需校核稳定性。
# 1.4 应力集中
应力集中是物体内应力局部增高的现象，常出现在缺口、孔洞、沟槽、几何突变和刚性约束处，可能引起疲劳裂纹或脆性断裂。

# 2. 截面的几何性质
本节涉及静矩、形心、惯性矩和惯性积。弯曲计算还需用到截面对指定轴的惯性矩。
# 2.2 静矩、形心和对称轴
静矩是微面积与其到坐标轴的有向距离的乘积在整个截面上的积分。
@1
静矩可能为正、负或零。不同截面对同一坐标轴、同一截面对不同坐标轴的静矩一般不同。
形心是截面图形的几何中心，形心坐标可由静矩和面积求得。
@2
截面对某轴的静矩为零，当且仅当该轴通过形心。矩形、圆形和等腰三角形等截面具有对称轴；多条对称轴的交点即为形心。

::011
对称轴必通过形心，因此截面对任一对称轴的静矩为零。但经过形心的轴不一定是对称轴。

# 3. 压杆稳定
细长杆在轴向压力达到一定值时可能突然侧向弯曲并丧失承载能力，称为失稳。受压杆的稳定性是其直线平衡状态抵抗微小扰动的能力。
当压力小于临界压力时，直线平衡状态稳定；超过临界压力后，该状态失稳。临界压力记为 F_cr。

::028
# 3.3 欧拉公式
