六数字电子技术

1.数字信号与逻辑函数

1.1数字信号如何表达信息

数字信号在时间和幅值上离散，常以两种物理状态表示 0 和 1。通过编码，可用一串二进制数字表示特定信息。

七段显示器的段序为 a、b、c、d、e、f、g。共阴极接法高电平点亮，显示 0 的段码为 1111110；共阳极接法低电平点亮，显示 3 的段码为 0000110。

1.2逻辑函数

在二值逻辑中，逻辑加表示或，逻辑乘表示与。例如

0∨0=0,0∨1=1,1∨1=10\lor0=0,\quad 0\lor1=1,\quad 1\lor1=1
1∧0=0,1∧1=11\land0=0,\qquad 1\land1=1

逻辑变量的反（¬A）与 A 的值相反。可以对输入组合逐一求值，列真值表核对逻辑函数。

2.BCD码

2.1放弃二进制、十六进制等其他进制数字信号相关知识点的原因

有关各进制数字信号的历年考试题目，基本均与BCD码相关。因此本小节仅对BCD码进行展开学习，并放弃其他知识点。

七段显示器的段位与逻辑运算表

a、g、d 分别位于上横、中横、下横。右侧上、下竖段分别为 b、c，左侧下、上竖段分别为 e、f。右下角 DP 是独立小数点，七位段码按 a 到 g 的顺序书写。

显示器与目标数字点亮的段段码（abcdefg）
共阴极显示 0a、b、c、d、e、f1111110
共阳极显示 3a、b、c、d、g0000110
基本律恒等式
交换律A ∨ B = B ∨ A
交换律A ∧ B = B ∧ A
结合律A ∨ (B ∨ C) = (A ∨ B) ∨ C
结合律A ∧ (B ∧ C) = (A ∧ B) ∧ C
分配律A ∨ (B ∧ C) = (A ∨ B) ∧ (A ∨ C)
分配律A ∧ (B ∨ C) = (A ∧ B) ∨ (A ∧ C)
互补律A ∨ ¬A = 1
互补律A ∧ ¬A = 0
与常量运算A ∨ 0 = A
与常量运算A ∨ 1 = 1
与常量运算A ∧ 1 = A
与常量运算A ∧ 0 = 0

2.2BCD码的概念

BCD码（8421码)，用4位二进制数来表示1位十进制数中的0～9这10个数码。这是一种二进制的数字编码形式，用二进制编码的十进制代码，使二进制和十进制之间的转换得以快捷的进行。例如：

8421 码每一组四位分别表示一个十进制数字。例如 32、89、56 的编码分别为 0011 0010、1000 1001、0101 0110。
