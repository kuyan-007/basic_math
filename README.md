# 知序 · 工程学习空间

知序是一套面向工程公共基础学习与复习的静态网站。可以按学科阅读章节、查找知识点，再用问答卡片安排间隔复习。

## 学习内容

| 类别 | 学科 |
| --- | --- |
| 数理基础 | 高等数学、大学物理、普通化学 |
| 工程力学 | 理论力学、材料力学、流体力学 |
| 电气与信息 | 电工电子、信号与信息、计算机技术 |
| 工程管理 | 工程经济、法律法规 |

## 主要功能

- **查阅资料**：按学科、章、节浏览课程正文、公式和图表。首页支持按类别筛选及搜索学科或章节，学科页支持搜索章节和知识点。
- **卡片复习**：按全站、学科、章或节选择范围，也可只复习公式与矩阵。查看答案后，按「忘记了」「模糊」「记住了」评分，系统据此安排下次复习时间。
- **跟踪进度**：查看到期卡片、新卡片、各学科复习进度和估算记忆曲线。进度保存在当前浏览器，同一网站使用不同 IP 或端口访问时会分别记录。
- **阅读体验**：适配手机和桌面，支持主题切换。侧栏还提供「箭头逃亡」小游戏。

## 本地运行

网站使用 HTML、CSS 和 JavaScript，无需构建或启动后端。安装 Python 3 后，在项目根目录运行以下命令。请先确认端口空闲，如已占用，可改用 `5000–5500` 内的其他空闲端口，并同步修改访问地址。

```powershell
python -m http.server 5000 --bind 127.0.0.1
```

在浏览器打开 `http://127.0.0.1:5000`。如果要从局域网内的其他设备访问，将命令和访问地址中的 `127.0.0.1` 换成运行服务的电脑的局域网 IPv4 地址。

| --- | --- |

| `tools/` | 课程资料和卡片的生成与处理脚本 |
